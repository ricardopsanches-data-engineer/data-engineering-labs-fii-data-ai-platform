# Project Overview

## Vision

Build a modern Data & AI platform on AWS for ingesting, processing, cataloging, validating and analyzing data related to Brazilian Real Estate Investment Funds (FIIs).

## Business Problem

FII data is fragmented across multiple sources, formats and update frequencies. The platform will consolidate historical and current data into a governed and queryable analytical foundation.

## Initial Goal

Deliver a production-inspired MVP focused first on reliable data engineering. AI capabilities will be introduced only after the data foundation is mature.

## Target Capabilities

- Historical FII data ingestion.
- Raw, curated and analytical data layers.
- Orchestration with Apache Airflow.
- Infrastructure as Code with Terraform.
- Data quality and observability.
- SQL-based analytics.
- Portfolio and quantitative analytics.
- Future Generative AI, RAG and agentic capabilities.
