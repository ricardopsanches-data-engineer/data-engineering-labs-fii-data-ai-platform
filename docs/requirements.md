# Requirements

## Functional Requirements

1. Ingest data from approved FII data sources.
2. Store raw source data with ingestion timestamps.
3. Transform data into standardized analytical models.
4. Preserve historical records where relevant.
5. Query curated data using SQL.
6. Calculate selected FII indicators.
7. Validate data quality before publishing analytical outputs.
8. Orchestrate pipelines automatically.

## Non-Functional Requirements

- Reproducible infrastructure.
- Low operational cost for a personal project.
- No secrets committed to Git.
- Idempotent pipelines where applicable.
- Automated tests.
- Logging and operational metrics.
- Data lineage and source traceability where feasible.
- Modular architecture that can evolve without major redesign.
